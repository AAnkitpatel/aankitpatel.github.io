Cutting Infrastructure Costs with a Multi-Cloud Comparison

Provisioning a full production architecture and benchmarking real pricing across an Indian cloud provider, AWS, and GCP.

Role: Solo DevOps engineer (architecture, provisioning, cost analysis)
Stack: E2E Networks · Terraform · PostgreSQL/Redis DBaaS · Autoscaling Groups · CDN · Cloudflare
Architecture diagram placeholder — add a diagram image here when available.

The problem

The client needed a full production architecture (VPC, database layer, autoscaling API and worker tiers, CDN, load balancing) and wanted to know whether AWS, GCP, or an Indian cloud provider gave the best cost-to-performance ratio before committing infrastructure spend.

What I did

  • Provisioned a full 10-resource production architecture: VPC, managed PostgreSQL and Redis (DBaaS), an autoscaling API server tier, a worker tier, CDN, and a load balancer.
  • Hit a persistent ALB 503 error under load and traced it to how the ASG-based backend groups were registering targets.
  • Built a detailed cost comparison report benchmarking equivalent specs across the Indian cloud provider, AWS, and GCP, priced in INR, so the client could compare real numbers instead of list prices in USD.
  • Migrated DNS to Cloudflare with Flexible SSL, reconfigured the load balancer to work behind Cloudflare's edge, and set up a 301 apex-to-www redirect using Cloudflare Redirect Rules.

Result

  • The cost report concluded the Indian cloud provider was 50-70% cheaper than AWS/GCP at equivalent specs, giving the client a concrete number to base their infrastructure decision on.
